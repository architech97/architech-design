# ArchiTECH — Residence in Vasant Kunj

Static residence presentation published at https://architechdesign.in/.

Based on the user-selected `hesa-residence` site from commit `a60f9f3ec8c14638a2de2cce24642770db7e129d` of architech97/architech-portfolio. The original repository is unchanged.

HTML, CSS and JavaScript; no build step. GitHub Pages publishes main from the repository root. The site uses Three.js, GSAP and Lenis from jsDelivr.

Branding and public contact details are updated for ArchiTECH. The legacy branded PDF is not included. The header, footer and loader use the supplied ArchiTECH logo with a transparent background. The original monogram is used as the favicon.
