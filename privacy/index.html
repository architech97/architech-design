Privacy

Navneet has not signed off on this page. It is a plain notice of how the site works today. Please read it before treating it as the published policy.

ArchiTECH is the site of Navneet Singh, an architect in New Delhi. Questions about this notice go to navneet@architechdesign.in.

What this site does not do

No analytics product is installed. There is no advertising tag, and no contact form is sent to a server. A blank place is left for a form later. It is not connected, and it does not collect or submit anything.

What a visit does

  • The site is a set of static pages on GitHub Pages. GitHub may keep ordinary server logs of requests. ArchiTECH does not run a separate store of those logs.
  • Email and phone links open the visitor's own mail or phone app. Social links leave this site for LinkedIn, Instagram, YouTube and X.
  • The Design page may set a sessionStorage flag named architech-intro so the same browser session does not repeat an introduction. That flag stays on the device. It is not sent to ArchiTECH.
  • Pages request typefaces from Google Fonts (fonts.googleapis.com and fonts.gstatic.com). That request is visible to Google.

If that changes

If an analytics service or a form backend is added, this page should be rewritten first and the new service named here. Nothing is collected for those purposes today.
